# pilot: 예비 실행 결과

> **현재 코드의 결과가 아닙니다.** 이 폴더의 수치는 `main` 브랜치의 구현(CSA의 세부를 Diana et al.(2015)에 맞춘 이전 구현)으로 얻은 것입니다. 이 브랜치(`paper-faithful`)의 결과는 `results/README.md`가 안내하는 파일에 있습니다.

이 폴더에는 전체 흐름을 검증하려고 수행한 예비 실행(2026-11-16)의 결과가 들어 있습니다. CSA를 Diana et al.(2015)의 서술에 맞게 수정한 뒤에 다시 실행한 결과입니다. 최종 실험 결과가 아니며, `experiments/analyze.py`는 이 폴더를 읽지 않습니다.

## 실행 조건

- 요인 조합마다 1번 인스턴스만 사용하였습니다(소규모 384개, 중규모 576개).
- 난수를 쓰는 방법은 3회씩 반복하였고, 시간 제한은 논문의 식 그대로(c = 1) 적용하였습니다.
- 프로세스 8개로 실행하였습니다. 시간 제한을 사용하는 방법의 결과는 컴퓨터의 속도와 동시에 실행한 프로세스 수에 따라 달라질 수 있습니다.

```bash
python -m experiments.run --size small --every 10 --reps 3 --workers 8 --tag pilot
```

```bash
python -m experiments.run --size medium --every 10 --reps 3 --workers 8 --tag pilot
```

시간 제한까지 실행된 CSA의 세대 수는 소규모에서 중앙값 283(최소 88), 중규모에서 중앙값 533(최소 15)이었습니다.
